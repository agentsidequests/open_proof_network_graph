## Reducing the count to a finite search

Write $R(a) = \{ n \in \mathbb{N} : \exists k \ge 1,\ 2k \le n,\ \binom{n}{k} = a \}$ for the set of rows holding $a$. The proof rests on two helper lemmas stated before the theorem.

**First helper** (`choose_mono_half`): if $r \le j \le \lfloor n/2 \rfloor$ then $\binom{n}{r} \le \binom{n}{j}$. This is an induction on $j$: the case $j = r$ is equality, and each step from $j$ to $j+1$ (with $j < n/2$) uses $\binom{n}{j} \le \binom{n}{j+1}$.

**Second helper** (`sol_set_eq`): if $2 \le a$ and $a < \binom{B+1}{2}$, then
$$R(a) = \{a\} \cup \{ n \le B : \exists k,\ 1 \le k \le \lfloor n/2 \rfloor,\ \binom{n}{k} = a \}.$$

For a row $n$ of $a$ with witness $k$: if $n \le B$ it lies in the second set. If $n > B$ and $k = 1$ then $n = \binom{n}{1} = a$. If $n > B$ and $k \ge 2$, the first lemma and monotonicity in the top index give $\binom{n}{k} \ge \binom{n}{2} \ge \binom{B+1}{2} > a$, a contradiction. Conversely $a$ is a row of itself through $\binom{a}{1} = a$, since $2 \le a$ gives $2 \cdot 1 \le a$, and every element of the second set is a row by its witness $k$.

## The case t = 3 {steps: close}

Take $a = 120$ and $B = 16$. The hypotheses of the second lemma hold: $2 \le 120$, and $\binom{17}{2} = 136 > 120$, checked by evaluation. So $R(120)$ is the finite set on the right, its cardinality is the cardinality of that finite set, and evaluating that set by computation (`decide`) finds exactly the rows $120$, $16$ and $10$ ($\binom{120}{1} = \binom{16}{2} = \binom{10}{3} = 120$). Hence $\# R(120) = 3$.
