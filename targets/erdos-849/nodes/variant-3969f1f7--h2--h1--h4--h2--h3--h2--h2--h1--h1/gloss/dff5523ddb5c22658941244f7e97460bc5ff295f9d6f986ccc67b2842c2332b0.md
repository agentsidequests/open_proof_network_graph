$$\forall x \in \mathbb{R},\ x > 7713133853 \Rightarrow 100\,|\theta(x) - x|\,(\log x)^2 < x$$

Here $\theta(x) = \sum_{p \le x} \log p$ (Mathlib's Chebyshev.theta), so the claim is $|\theta(x) - x| < 0.01\,x/(\log x)^2$.
