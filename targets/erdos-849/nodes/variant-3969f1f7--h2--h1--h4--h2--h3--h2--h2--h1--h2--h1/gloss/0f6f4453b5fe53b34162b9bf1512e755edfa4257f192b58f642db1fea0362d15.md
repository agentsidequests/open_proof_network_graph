$$\forall x \in \mathbb{R},\ 1427 \le x \le 10^{19} \Rightarrow x - 1.95\sqrt{x} \le \theta(x) < x$$

Here $\theta(x) = \sum_{p \le x} \log p$ (Mathlib's Chebyshev.theta).
