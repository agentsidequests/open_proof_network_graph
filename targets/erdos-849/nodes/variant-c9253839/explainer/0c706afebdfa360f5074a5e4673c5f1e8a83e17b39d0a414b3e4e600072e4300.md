## Overview

Write $R(a) = \{n \in \mathbb{N} : \exists k,\ 1 \le k,\ 2k \le n,\ \binom{n}{k} = a\}$ for the set of rows of Pascal's half triangle that hold the value $a$. The theorem asks for some $a$ with $|R(a)| = 4$. The proof takes $a = 3003$ and shows $R(3003) = \{14, 15, 78, 3003\}$: it first replaces $R(a)$ by a finite set that a computer can list, and then has the Lean kernel count that set. The four rows come from $\binom{14}{6} = \binom{15}{5} = \binom{78}{2} = \binom{3003}{1} = 3003$.

## Reducing the row set to a finite search {steps: close}

The proof rests on two auxiliary lemmas declared before the theorem.

**Lemma 1 (`choose_mono_half`).** If $r \le j \le \lfloor n/2 \rfloor$, then $\binom{n}{r} \le \binom{n}{j}$. This is induction on $j$: the case $j = r$ is trivial, and the step from $j$ to $j + 1$ (for $j + 1 \le n/2$, so $j < n/2$) is Mathlib's `Nat.choose_le_succ_of_lt_half_left`, $\binom{n}{j} \le \binom{n}{j+1}$.

**Lemma 2 (`sol_set_eq`).** Let $a \ge 2$ and let $B$ satisfy $a < \binom{B+1}{2}$. Then
$$R(a) = \{a\} \cup \{\, n \le B : \exists k \in [1, \lfloor n/2 \rfloor],\ \binom{n}{k} = a \,\}.$$
For $\subseteq$, take $n \in R(a)$ with its $k$. If $n \le B$, then $n$ lies in the second set (as $2k \le n$ gives $k \le \lfloor n/2 \rfloor$). If $n > B$ and $k = 1$, then $n = \binom{n}{1} = a$. If $n > B$ and $k \ge 2$, Lemma 1 gives $\binom{n}{2} \le \binom{n}{k} = a$, while monotonicity of $\binom{\cdot}{2}$ (Mathlib's `Nat.choose_le_choose`) and $n \ge B + 1$ give $\binom{n}{2} \ge \binom{B+1}{2} > a$, a contradiction. For $\supseteq$: $a \in R(a)$ with $k = 1$, because $a \ge 2$ makes $2 \cdot 1 \le a$; and an $n$ of the second set lies in $R(a)$ with the same $k$.

**The theorem.** Take $a = 3003$ and $B = 78$. The hypotheses of Lemma 2 hold: $2 \le 3003$, and $\binom{79}{2} = 3081 > 3003$ is checked by `decide`. Lemma 2 rewrites $R(3003)$ as the coercion of a finite set, so its `Set.ncard` is the cardinality of that finset (`Set.ncard_coe_finset`). The last step, `decide`, has the kernel evaluate that finset: it runs through $n \le 78$ and $1 \le k \le \lfloor n/2 \rfloor$, finds the set $\{14, 15, 78, 3003\}$, and confirms its cardinality is $4$.
