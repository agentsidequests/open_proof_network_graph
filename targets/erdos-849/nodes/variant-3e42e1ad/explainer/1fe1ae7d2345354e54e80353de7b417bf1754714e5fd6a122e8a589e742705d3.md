## Helper lemmas

Write $R(a) = \{ n \in \mathbb{N} : \exists k \ge 1,\ 2k \le n,\ \binom{n}{k} = a \}$ for the set of rows holding $a$. Four helper lemmas come before the theorem.

**`v3e_choose_strict`**: for $k \ge 1$ and $k \le n < m$, $\binom{n}{k} < \binom{m}{k}$ (induction on $m$; the first step is Pascal's rule $\binom{n+1}{j+1} = \binom{n}{j} + \binom{n}{j+1}$ with $\binom{n}{j} > 0$, each later step uses $\binom{m}{k} \le \binom{m+1}{k}$).

**`v3e_choose_mono_k`**: for $j \le k$ and $2k \le n$, $\binom{n}{j} \le \binom{n}{k}$ (induction on $k$ from $j$, each step $\binom{n}{k} \le \binom{n}{k+1}$ for $k < n/2$).

**`v3e_prime_le`**: if $p$ is prime, $k \le n$ and $p \mid \binom{n}{k}$, then $p \le n$: from $\binom{n}{k}\, k!\, (n-k)! = n!$ we get $p \mid n!$, and a prime divides $n!$ only if $p \le n$.

**`v3e_one_row`**: for a prime $p \ge 4$, $R(p) = \{p\}$. The row $p$ holds $p$ through $\binom{p}{1}$. Conversely let $\binom{n}{k} = p$ with $k \ge 1$, $2k \le n$. If $k = 1$ then $n = p$. If $k \ge 2$, then $p \le n$ by `v3e_prime_le`, while $\binom{n}{k} \ge \binom{n}{2} = n(n-1)/2 > n$ (as $n \ge 2k \ge 4$), so $p > n$: a contradiction.

**`v3e_two_rows`**: for a prime $p \ge 7$, $R\bigl(\binom{p}{2}\bigr) = \{\binom{p}{2},\ p\}$. First, $\binom{p}{2} = p(p-1)/2$ and $p(p-1)$ is even, so $2\binom{p}{2} = p(p-1)$; hence $p \mid 2\binom{p}{2}$, and as $p \nmid 2$ (since $p \ge 7$), $p \mid \binom{p}{2}$. Also $p < \binom{p}{2}$. Both $\binom{p}{2}$ (via $k = 1$) and $p$ (via $k = 2$, $4 \le p$) are rows. Conversely let $\binom{n}{k} = \binom{p}{2}$ with $k \ge 1$, $2k \le n$. If $k = 1$, $n = \binom{p}{2}$. If $k \ge 2$, then $p \le n$ by `v3e_prime_le`; if $p < n$ then $\binom{p}{2} < \binom{n}{2} \le \binom{n}{k}$ by the first two helpers, a contradiction, so $n = p$.

## Choosing the prime {steps: s1}

Given $N$, take a prime $p \ge N + 7$ (there are infinitely many primes, `Nat.exists_infinite_primes`).

## Exactly one row {steps: s2}

$a = p$ satisfies $a \ge N$, and $\# R(p) = \#\{p\} = 1$ by `v3e_one_row` (as $p \ge 4$).

## Exactly two rows: the size of b {steps: s3}

For $b = \binom{p}{2} = p(p-1)/2$: since $p - 1 \ge 6$, $p(p-1) \ge 6p$, so $b \ge 3p \ge N$.

## Exactly two rows: the count {steps: s4}

By `v3e_two_rows`, $R(b) = \{b, p\}$, and $b \ne p$ because $b \ge 3p > p$ (the same computation as the previous section); so $\# R(b) = 2$.
