$$\Big(\forall t \ge 1,\ \exists a \in \mathbb{N},\ |R(a)| = t\Big) \;\Longrightarrow\; \forall N \in \mathbb{N},\ \exists a \ge N,\ 3 \le |R(a)|, \qquad R(a) = \{\, n \in \mathbb{N} : \exists k \ge 1,\ 2k \le n,\ \tbinom{n}{k} = a \,\}.$$

The hypothesis is the root statement of Erdős 849 (every multiplicity $t \ge 1$ is attained by some $a$); the conclusion is this node's statement. $|R(a)|$ is Lean's `Set.ncard`, which is $0$ on an infinite set; every $R(a)$ here is finite, as $R(a) \subseteq [2, a]$.

The file proves the implication: if every $a \ge N$ had $|R(a)| \le 2$, the values $a_t$ with $|R(a_t)| = t + 3$ for $t = 0, 1, \dots, N$ would all lie below $N$, so two of these $N + 1$ values would coincide by the pigeonhole principle, giving two different cardinalities for one set.
