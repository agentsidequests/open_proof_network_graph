## Overview

The statement is a case split for a collision $\binom{n}{k} = \binom{m}{l}$ with $2 \le k \le n/2$, $2 \le l \le m/2$ and $k < l$: one of the listed cases holds. This partial proof sets one more region aside, $n > 4021520$, $16598m \le 16597n$ and $n \le 16598k$, and shows that no collision lies there, because a prime in a short interval divides $\binom{n}{k}$ but not $\binom{m}{l}$. It leaves two holes: the prime-gap theorem of Schoenfeld (Math. Comp. 30 (1976)), as quoted by Dusart, and the statement with the new region added as one more case.

## A prime separating the two binomials {steps: h_sep}

**Lemma.** Let $2k \le n$, $2l \le m$, and let $p$ be a prime with $m < p$, $n - k < p$ and $p \le n$. Then $\binom{n}{k} \ne \binom{m}{l}$.

First, $p \mid \binom{n}{k}$ (`h_sep.h1`): writing $n = k + (n - k)$, Mathlib's `Nat.Prime.dvd_choose_add` says a prime $p$ divides $\binom{a+b}{a}$ when $a < p$, $b < p$ and $p \le a + b$; here $a = k \le n - k < p$, $b = n - k < p$ and $p \le n$. Second, $p \nmid \binom{m}{l}$ (`h_sep.h2`): $\binom{m}{l}$ divides $m!$, because $\binom{m}{l}\, l!\,(m-l)! = m!$, so $p \mid \binom{m}{l}$ would give $p \mid m!$ and hence $p \le m$, against $m < p$. The two together contradict $\binom{n}{k} = \binom{m}{l}$.

## Assembly {steps: s4 s5}

Given a collision, the second hole gives either one of the statement's own cases, which is the conclusion, or the region $n > 4021520$, $16598m \le 16597n$ and $n \le 16598k$. In that region put $x = \max(m, n - k)$. Then $x \ge 2010760$, since $n - k \ge n/2 > 2010760$, so the first hole gives a prime $p$ with $x < p$ and $16597p < 16598x$. To apply the lemma it remains to see $p \le n$: if $x = m$ this follows from $16598m \le 16597n$, and if $x = n - k$ from $n \le 16598k$, i.e. $16598(n-k) \le 16597n$; in both cases $16597p < 16598x \le 16597n$, so $p < n$.
