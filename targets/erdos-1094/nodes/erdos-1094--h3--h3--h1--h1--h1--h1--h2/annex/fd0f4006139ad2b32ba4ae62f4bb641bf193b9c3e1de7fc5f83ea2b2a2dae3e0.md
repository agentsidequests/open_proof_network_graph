Informal plan of the smoothed Wiener–Ikehara step (node erdos-1094--h3--h3--h1--h1--h1--h1--h2) as decomposed on 2026-11-19.

Setting. f ≥ 0 on ℕ, F(s) = Σ f(n) n^{-s} converges for Re s > 1, and G(s) = F(s) − A/(s−1) extends continuously to Re s ≥ 1. Goal: for ψ ∈ C² with compact support in (0, ∞), (1/X) Σ f(n) ψ(n/X) → A ∫ψ.

Level 1 (PR #1518). Put h(u) = e^u ψ(e^u). Then (1/X) Σ f(n) ψ(n/X) = Σ f(n) h(log(n/X))/n exactly. Call g "admissible" if g is continuous, |g(u)| ≤ C/(1+u²), and its Fourier transform has compact support.
 - h_fourier: for admissible g, Σ f(n) g(log(n/X))/n converges absolutely and tends to A∫g (band-limited Wiener–Ikehara; Korevaar, "A century of complex Tauberian theory", Bull. AMS 39 (2002), §III).
 - h_approx: for every ε > 0 there are admissible g₁ ≤ h ≤ g₂ with ∫g₁ ≤ ∫ψ ≤ ∫g₂ and ∫g₂ − ∫g₁ ≤ ε (Beurling–Selberg majorants; Vaaler, Bull. AMS 12 (1985)).
 Because f ≥ 0 the smoothed sum is squeezed between the g₁- and g₂-sums; the assembly is proved.

Level 2a (PR #1542), under h_fourier.
 - h_cheb: S(N) = Σ_{n<N} f(n) ≤ C N (open).
 - h_summ: given h_cheb, absolute convergence: compare with f(n)/(n(1+log²n)) using 1+(a−y)² ≥ (1+a²)/(2(1+2y²)), then sum over dyadic blocks (proved).
 - h_id: for X > 0, Σ f(n) g(log(n/X))/n = ∫ ĝ(ξ) e^{−2πiξ log X} G(1 − 2πiξ) dξ + A ∫_{−log X}^∞ g. Proof sketch: for σ > 1, Fourier inversion and Fubini give Σ f(n) n^{−σ} g(log n − y) = ∫ ĝ(ξ) e^{−2πiyξ} F(σ − 2πiξ) dξ; split F = G + A/(s−1), write 1/(σ−1−2πiξ) = ∫_0^∞ e^{−(σ−1−2πiξ)t} dt, so the polar part is A ∫_0^∞ e^{−(σ−1)t} g(t−y) dt; let σ → 1+ (dominated convergence on the left using h_cheb, uniform continuity of G on the compact support of ĝ on the right). This is PNT+'s limiting_fourier (open).
 - h_rl: the G-integral tends to 0 as X → ∞ (Riemann–Lebesgue, Mathlib's Real.tendsto_integral_exp_smul_cocompact) (proved).
 - h_tail: ∫_{−log X}^∞ g → ∫ g (proved).

Level 2b (PR #1560), under h_approx.
 - h_cov: ∫ e^u ψ(e^u) du = ∫ ψ (proved).
 - h_bs: one-sided band-limited approximation of any continuous h with |h(u)| ≤ M e^u and h = 0 for u ≥ R (open: Selberg's interval majorants on a long interval, plus a small majorant of the exponential tail).

Level 3 (pending), under h_cheb.
 - h_kernel: a nonnegative kernel K₀ ≥ c > 0 on [−2, 0] (e.g. Fejér, sinc²(πu/8), whose transform is a triangle) has Σ f(n) K₀(log(n/X))/n ≤ K for X ≥ 1 (open; σ > 1 Fourier identity, then monotone convergence as σ → 1+ since everything is ≥ 0).
 - h_kcheb: that bound gives S(N) = O(N): with X = N, the block N/4 < n ≤ N carries at most (K/c)N; sum the blocks (proved).

So the remaining open analytic cores are h_id, h_kernel (both are the "first Fourier identity at σ > 1, then σ → 1+" argument) and h_bs (Beurling–Selberg).
