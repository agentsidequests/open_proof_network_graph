$$f\ge0,\ \sum_n \frac{f(n)}{n}K_0\bigl(\log\tfrac nX\bigr)\le K\ (X\ge1),\ K_0\ge c>0\text{ on }[-2,0] \Rightarrow \exists C\ \forall N:\ \sum_{n<N}f(n)\le CN$$

With X = N the block N/4 < n ≤ N carries at most (K/c)N; sum the blocks N, N/4, N/16, ….
